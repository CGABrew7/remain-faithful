# Remain Faithful 1.0.5 Play declaration draft

Draft for the owner. Do not paste this into Play Console until you choose a model and record the demo. This file does not submit a build.

## Foreground service: mediaProjection

Deep Scan is a session the user starts from inside Remain Faithful. Android shows the system screen-capture consent. A foreground service of type mediaProjection runs only after that consent. The ongoing notification stays visible for the session. The user can stop the session from the system chip or from the app.

If the service is delayed or interrupted, Deep Scan stops. Alerts and Blocking continue as the user set them. The app does not start this service from BOOT_COMPLETED. A capture token is not reused for a second virtual display.

## What the session does

While the session is on, frames can be read in memory on the phone. They are closed immediately. They are not written to disk, not logged, and not uploaded. The notices that already leave the phone are "Deep Scan stopped" when the session ends, using the existing protection alert. No frame, score, box, or category is added in 1.0.5.

A blur overlay is implemented for a user-started session. It is not shown in this build because no model weights are included. See 1.0.5-android-blur-license.md. Do not tell Play that the app blurs images until a model is in the binary you upload and you have watched it on a device.

The service is not an accessibility tool. isAccessibilityTool is not set.

Protected video such as Netflix stays in its own player. The session does not bypass that.

## Demo video, when a model is included

1. Open Remain Faithful and start Deep Scan.
2. Show the Android system consent dialog and accept it.
3. Show the system capture chip staying visible.
4. Show a sensitive image becoming blurred on the phone, then stop the session and show the blur gone.
5. Say that the screen is not uploaded.

## Data safety

Microphone: recorded by the user, stored on the device, not collected by the developer.
Screen capture: processed on the device during a session the user starts, not collected.
Partner check-in: one fixed sentence and a time, only after the user opts in.

## Listing line

Deep Scan is a session you start. Android shows the capture notice the whole time. The screen stays on the phone.

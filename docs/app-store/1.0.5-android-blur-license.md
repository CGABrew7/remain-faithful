# Android blur model, 1.0.5

Decision for this pull request: no weight file is added.

Shade and similar public detectors are AGPL or carry a non-commercial limit. This repository is public, so those weights stay out. No first-party model has been trained, and no permissively licensed classifier was selected.

What is in the branch:

- Capture stays at the existing 32 by 32 size until a scorer is marked ready. The working size of 480 pixels on the long edge is implemented and covered by a unit test.
- Frames are closed in memory. The hygiene rule returns no file path.
- A sensitivity threshold maps a user setting to a score cutoff. A box, when a future model returns one, blurs that region. A score alone uses a full-screen veil.
- The veil is not touchable, is removed when the session ends, and is not drawn before a score exists.
- `BlurPolicy.weightsReady()` is false, so the consent line about blurring images is not shown yet.

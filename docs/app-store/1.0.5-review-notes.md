# Remain Faithful 1.0.5 App Review notes

Draft for the owner. Do not submit this text until 1.0.4 is approved and you have checked it against the binary you upload.

Bundle ID: com.remainfaithful.app
Apple ID: 6774615426
This is the same app already on the store. Marketing version for this draft is 1.0.5. This file does not bump or submit a build.

Family Controls, Managed Settings, and Device Activity shield apps the user selected. Authorization uses FamilyControlsMember.individual.

The Shield Configuration extension (com.remainfaithful.app.ShieldConfig) returns a ShieldConfiguration. It makes no network calls. It does not write an app name, bundle id, or domain.

The Shield Action extension (com.remainfaithful.app.ShieldAction) handles the primary button. On iOS 26.5 and later, the response is ShieldActionResponse.openParentalControlsApp. On earlier versions the extension closes the shield and posts a local notification that opens Remain Faithful. The app then shows "A blocked app was opened" with Tell my partner and Not now. The network call happens only after Tell my partner, from the main app. A short recording the user made for themselves can play on that screen. Skip does not notify a partner. The recording stays on the phone.

The Device Activity monitor extension (com.remainfaithful.app.DeviceActivityMonitor) applies and removes shields on the phone. It may write a local timestamp when a scheduled threshold is reached. It makes no network calls. It does not load a model.

Server calls from the main app, in addition to the 1.0.4 list:

- POST /protection/alerts with type coach_nudge after the user turns on partner check-ins and taps Check in now. Fields: type, detail. Detail is the fixed sentence "Your partner would welcome a word from you today." The phone's UTC offset may be sent as offset_minutes so the one-a-day cap follows the local calendar day. The offset is not stored. Not now does not send this notice.

Apple Screen Time keeps the apps you chose shielded. Deep Scan is an optional session you start, with the system recording indicator on, and classification stays on the phone.

On an iPhone where Apple Intelligence is on and the on-device model is ready, Remain Faithful may warm the local check-in words on the phone. The partner sentence is never rewritten. If the model is unavailable, the fixed check-in words are used. Settings names this as "Warm the check-in words on this iPhone."

The microphone is used only so the user can record a short message to themselves. The files live in the app sandbox, are excluded from backup, and are deleted on sign-out and account deletion.

One bundle ID. Coach nudges are sent from the main app after opt-in.

# Reply draft for guideline 4.3

Draft for the owner to send in App Store Connect. Do not post it from this repository.

Guideline 4.3(a) is about multiple bundle IDs of the same app. Remain Faithful is one bundle ID, com.remainfaithful.app, sold by Jeffrey Brewer, on the store as version 1.0 since 13 October 2026. Apple ID 6774615426. There is no second city, team, or white-label app.

Version 1.0.4 removes the Screen Time extension uploads from the previous binary. The Shield Configuration extension and the Device Activity monitor extension make no network calls. Shields stay on the device. A partner notice about a blocked app is sent from the main app after the user taps Tell my partner. The notice is a fixed sentence and a time.

The binary also includes an optional Session Shield. The user turns it on after a consent screen that names the partner or covenant group and lists the fields. Chosen apps stay shielded until the user starts a Deep Scan broadcast from the system picker. iOS shows the recording indicator. What a partner can receive from that session is a category, a severity, a confidence level, and a time, plus a notice when the recording stops.

That is a different product from a DNS filter, a VPN with a certificate, an MDM profile, or a broadcast that uploads screenshots. The features in this binary are a partner or a covenant group of up to 12, always-on Screen Time shields, a Partner PIN, user-confirmed notices, on-device classification during a broadcast the user starts, and public source.
